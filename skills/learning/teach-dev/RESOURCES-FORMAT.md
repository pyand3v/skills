# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for one topic. It gives lessons a durable research base and records the most useful source for each kind of question.

## Template

```md
# {Topic} Resources

## Knowledge

- [Official guide: {Title}](https://example.com)
  {What it covers and when to use it. Lessons: 0001-topic-basics.}

## Wisdom and practice

- [{Community, mentor, or practice venue}](https://example.com)
  {What practical perspective it offers and when to use it.}

## Gaps

- {A mission-relevant area that still needs a trustworthy source.}
```

## Rules

- Prefer primary sources, specifications, official documentation, respected maintainers, and well-moderated practitioner communities.
- Annotate every entry with its coverage and intended use; include related lesson numbers when known.
- Keep knowledge sources distinct from communities and other practice-oriented wisdom.
- Surface mission-relevant research gaps explicitly.
- Remove sources that prove inaccurate, shallow, or off-mission, and record a learner's community preferences so they are respected later.
