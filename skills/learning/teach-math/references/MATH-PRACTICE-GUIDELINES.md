# Math Practice Guidelines

Choose the smallest practice sequence that gives the learner useful evidence about the target capability.

## Worked reasoning

- State the goal, givens, assumptions, and the relevant definition, theorem, or strategy.
- Show intermediate steps and justify transitions that are not mechanical.
- Name why the chosen method applies and where it would not.
- Use a second representation—diagram, table, symbolic form, concrete instance, or verbal interpretation—only when it reveals a useful relationship.

## Progressive independence

1. Work one representative example while making the choices visible.
2. Give a near-transfer problem with only the prompts the learner needs.
3. Ask for an independent solution, explanation, proof outline, or critique.

Vary one meaningful dimension between problems. Do not create a long problem set when one or two well-chosen attempts will reveal the next learning need.

## Proofs and logical arguments

- Ask the learner to identify the precise statement, quantifiers or domain, and assumptions before judging a proof.
- Separate a statement being true from the presented argument proving it.
- Locate the first unsupported inference, missing case, circular step, or ambiguous term; explain the local repair before rewriting the whole proof.
- Use a counterexample to refute an overgeneralization, and verify that it satisfies the stated assumptions.
- Treat a complete proof as demonstrated only when the learner can explain the key structure and dependencies, not merely reproduce notation.

## Calculation and tools

- Ask for enough intermediate work to distinguish arithmetic slips from a wrong model or method.
- Check an answer using an inverse operation, estimate, boundary case, alternate representation, or independent computation when proportionate.
- A calculator, CAS, or code check may validate a result, but it does not establish understanding by itself. State what the tool verified and what reasoning remains the learner's.

## Feedback

Classify feedback concretely: sound reasoning, partial reasoning, computational slip, misconception, or missing condition. Correct the smallest issue that prevents progress, then offer a comparable retry. Do not use a numeric grade as a proxy for evidence.
