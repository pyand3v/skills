# GLOSSARY.md Format

`GLOSSARY.md` is the canonical language for one topic workspace. Explanations, exercises, progress notes, and learning records should use its terms consistently. Adding a concise definition is evidence that the learner understands a concept; it is not a list of terms to memorize.

## Template

```md
# {Topic} Glossary

{One or two sentences describing the topic this glossary covers.}

## Terms

**Deliberate practice**:
Focused practice designed to improve a clearly defined capability through feedback and adjustment.
_Avoid_: Repetition, doing more
```

## Rules

- Add a term only after the learner can use it correctly.
- Define what the term is in one or two sentences, not how to perform a task with it.
- Prefer one precise term for each concept; list ambiguous aliases under `_Avoid_` when helpful.
- Reuse established glossary terms in later definitions and teaching material.
- Group related terms under subheadings when that improves scanning.
- Record any deliberate resolution of a field-wide ambiguity, and revise definitions as understanding deepens.
