# GLOSSARY.md Format

`GLOSSARY.md` is the canonical terminology for one source study. Notes, retrieval prompts, and learning records should use its terms consistently. It records demonstrated understanding, not every unfamiliar word encountered.

## Template

```md
# {Source title} Glossary

## Terms

**Structural sharing**:
Reusing unchanged parts of an earlier data structure when creating a new version.
_Avoid_: copying the entire structure
```

## Rules

- Add a term only after the learner can use it correctly.
- Define what the term means in one or two sentences, not the entire procedure associated with it.
- Prefer one precise term for each concept; list misleading aliases under `_Avoid_` when helpful.
- Reuse established glossary terms in later notes and prompts.
- Group related terms under subheadings when that improves scanning.
