# Section Note Format

Section notes live in a source workspace's `notes/` directory and use sequential filenames such as `0001-structural-sharing.md`. They are concise study aids, not replacements for the source.

## Template

```md
# {Section title}

## Objective
{What the learner should be able to explain, compare, or apply after this section.}

## Scope
{The exact section, pages, or concepts covered.}

## Key ideas
- {A concise paraphrased claim or relationship.}
- {Another concise claim or relationship.}

## Example or connection
{A worked example, analogy, or link to an earlier demonstrated concept.}

## Retrieval prompts
1. {A recall or application question}
2. {Another question}

## Application
{An optional small scenario, analysis, explanation, or task that makes the section useful beyond recall.}

## Verification
{How to assess the learner's response and the smallest useful correction if it is incomplete.}

## Source notes
- {Section heading, page, anchor, or short citation}

## Open questions
- {Anything that remains unclear or needs verification}
```

## Rules

- Number each new note one higher than the greatest existing note number.
- Prefer paraphrase and short citations; do not copy large passages or recreate the source.
- Keep claims traceable to the source, and label supplemental material clearly.
- Include only retrieval prompts that exercise the current section's learning goal.
- Omit application or verification when they add no value; use them when the source teaches a decision, method, argument, or skill that can be applied.
