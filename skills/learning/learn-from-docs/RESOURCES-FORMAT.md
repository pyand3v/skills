# RESOURCES.md Format

`RESOURCES.md` lists supplemental material for one source study. The learner-supplied anchor belongs in `SOURCE.md`; this file records only material used to clarify, update, or extend it.

## Template

```md
# {Source title} Supplemental Resources

## Clarifications and updates

- [Official reference: {Title}](https://example.com)
  {What it clarifies or updates. Notes: 0001-section-title.}

## Follow-up

- [{Title}](https://example.com)
  {Why it is the next useful source after the agreed scope.}

## Gaps

- {A source claim or open question that still needs a trustworthy source.}
```

## Rules

- Do not duplicate the anchor source from `SOURCE.md` here.
- Annotate every entry with its purpose and related note numbers when known.
- Prefer primary sources, specifications, official documentation, respected maintainers, and high-quality scholarly material when appropriate.
- Clearly distinguish a source's original claims from later clarification or correction.
