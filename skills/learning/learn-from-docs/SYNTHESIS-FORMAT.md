# SYNTHESIS.md Format

`SYNTHESIS.md` is created when a source study reaches its agreed scope. It answers the study mission in the learner's own context without reproducing the source or pretending that every page was covered.

## Template

```md
# {Source title} Synthesis

## Mission answer
{A concise answer to what the learner set out to understand or do.}

## Key relationships
- {A central claim, mechanism, or argument in paraphrased form.}
- {How it connects to another key idea or constraint.}

## Practical implications
- {How the learner can use this understanding in their work, study, or decision.}

## Source limits and uncertainty
- {What the agreed scope did not cover, or a limitation that affects application.}

## Demonstrated evidence
- {The explanation, application, comparison, or task that supports completion.}

## Open questions and next material
- {A remaining question or the most relevant next source.}
```

## Rules

- Create this only after the agreed scope is complete or the learner explicitly closes the study.
- Keep it concise and mission-oriented; link to section notes instead of duplicating them.
- Distinguish the source's claims, the learner's application, and any supplemental material.
- State meaningful limitations or unresolved questions rather than overstating mastery.
