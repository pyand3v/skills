# SOURCE.md Format

`SOURCE.md` anchors one source study. It combines the source's identifying details with the learner's study mission, so the agreed scope and desired outcome remain visible together.

## Template

```md
# {Source title}

## Source
- Author or publisher: {name, if known}
- Location: {URL or local path}
- Edition, version, or date: {when relevant}

## Study mission
{One to three sentences describing why the learner is studying this source and what they need to do with it.}

## Scope
- Include: {chapters, sections, pages, or concepts}
- Exclude: {material that is intentionally out of scope}

## Success looks like
- {A specific, observable capability or explanation}
- {Another specific, observable capability or explanation}

## Constraints
- {Time, depth, accessibility, or context constraints}
```

## Rules

- Record a stable URL or exact local path whenever possible.
- Capture edition, version, date, or access date when it could change interpretation.
- Keep the scope bounded; clarify a vague source or goal before creating a long study path.
- Update the mission or scope when it materially changes, then write a learning record explaining why.
