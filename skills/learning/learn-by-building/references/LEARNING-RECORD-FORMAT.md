# Learning Record Format

Learning records retain evidence that should change later build decisions or teaching. Use sequential filenames such as `0001-learner-explained-input-validation.md`.

## Template

```md
# {What was established}

{One to three sentences describing what the learner demonstrated, disclosed, or corrected and why it changes the remaining project.}

## Evidence
{A correct explanation, verified behavior, completed task, or stated prior knowledge.}
```

## Rules

- Create a record only for non-trivial demonstrated understanding, stated prior knowledge, a corrected misconception, or a material mission change.
- Do not create records for ordinary coding activity or a passed check alone.
- Mark superseded records rather than deleting them.
